# 轻量插件与滚动长截图实施规划

## 目标与范围

以 .NET 10 / Windows 10 2004+ / WinForms 为基线，建立进程内 C# 插件机制，将纵向长截图作为第一个官方插件。用户从托盘选择长截图、框选内容、自动滚动拼接、预览结果，然后复制、保存或贴图；也可切换为手动模式。已有普通截图、OCR、翻译和首选项保持可用。

第一版交付插件 SDK、插件管理窗口、版本检查、四类扩展点、独立依赖加载、长截图、自动滚动、撤销和暂停、长图预览及发布集成。横向或反向拼接、浏览器整页、插件商店、热更新、独立进程和标注画布作为后续阶段。插件不是对所有软件都能成功的承诺：受保护内容、快速滚动导致无重叠、视频、重复列表和布局变化需要暂停并调整选区。

## 架构与边界

| 模块 | 职责 |
| --- | --- |
| SnipLite.Plugin.Abstractions | 公共接口、版本、命令与图像所有权约定；独立于主程序内部类 |
| SnipLite / Plugins | 发现、验证清单、依赖加载、注册、执行、取消、管理、宿主服务 |
| SnipLite.ScrollCapture | 官方 DLL 插件；匹配、分段缓存、捕获会话 UI |
| 宿主图像预览 | 可滚动原尺寸预览、缩放适配、裁剪、复制、保存、贴图；复用输出设置 |

只依赖 SDK 的插件可以注册命令、截图提供器、图像处理器和输出提供器。宿主将提供器自动适配为托盘命令；图像处理和输出先使用用户框选的图像，预览窗口也提供处理和输出入口。新增既有扩展点内的功能不需要修改主程序；新增宿主能力时升级 SDK。

## 插件协议与兼容性

- 每个插件目录包含 plugin.json、入口 DLL、deps.json 和私有依赖。插件以独立模块开发。v0.3.15 将官方长截图模块随主程序发放。首选项支持导入 ZIP/snipplugin 或通过 HTTPS 直链下载安装到 LocalAppData/SnipLite/Plugins；安装后默认停用，手动开启立即加载。
- 清单包含 id、name、version、apiVersion、minHostVersion、entryAssembly、entryType、architecture。ID 稳定且唯一；清单重复、路径越界、API 主版本不符、宿主版本过低、架构不符和损坏文件均记录状态，不阻止启动。
- 每个插件使用独立 AssemblyLoadContext 和 AssemblyDependencyResolver；公共 SDK 始终从默认上下文共享，避免接口类型身份冲突。SDK v1 接口冻结，未来通过新可选接口增加能力；破坏变更使用新的 API 主版本。
- 进程内插件属于可信代码，与主程序拥有相同权限。能力清单不是安全沙箱。异常记录并反馈；无法强制终止恶意代码或阻塞线程。
- 第一版导入、下载和启停即时生效，更新 DLL 仍需退出软件。停用移除可用贡献并取消当前任务，保留已加载程序集到退出，不依赖即时动态卸载。注册返回 IDisposable，宿主也记录并统一释放；初始化失败回滚全部注册。执行使用 CancellationToken，同一时间只允许一个交互插件任务；退出时取消活动会话。
- 插件命令默认无全局快捷键。启用插件后，可在「首选项 → 控制 → 全局快捷键」底部设置。全局快捷键开关也适用于插件，设置时会检查与其他命令的冲突。

## 图像、线程与坐标约定

- 宿主调用插件入口和交互命令的线程为 UI 线程。CPU 密集匹配在工作线程运行，任何窗体和剪贴板操作回到 UI 线程。取消贯穿选区、会话和输出。
- 屏幕选区使用物理像素，可包含多显示器负坐标。SourceBounds 只说明来源位置，Bitmap.Size 表示最终图像尺寸，两者不能混用。
- 截图结果 PluginImage 拥有 Bitmap，接收方负责释放；处理器/输出器的输入是借用对象，不得释放或异步保留。预览借用输入，贴图时复制一份并转移给 PinForm。
- 首版预算：单帧最大 16 MP、最终最大 32 MP、最终最大高度 30000 像素、最多 512 段、磁盘缓存最大 256 MiB。捕获期间只常驻当前帧及相邻帧特征，新增条带与撤销特征缓存至临时目录；每次完成或取消清理目录。完整长图仅在完成时构建。

## 长截图流程与算法

1. 冻结桌面用于框选，Esc 取消；选区确认后关闭遮罩。控制条置于选区外，无法容纳时提示缩小选区，避免控制条进入结果。
2. 记录首帧。默认自动模式先以一个滚轮刻度测量实际位移，此后根据选区高度与实测位移调整为每次约半个选区高度（非显示器半屏），每步 1–6 个刻度，逐步加速。至少等待 420ms 并确认画面稳定、匹配成功后才滚动下一步；手动模式只采样。匹配任务串行执行，取消或暂停后不提交迟到结果。
3. 通过连续样本确认画面稳定，避免拼接滚动动画中间帧。沿纵向估计位移，多列稀疏采样粗搜，候选按像素细查；要求足够重叠、纹理和唯一性。
4. 静止帧不追加；反向滚动、无可靠重叠或明显变动不追加。显示状态，允许用户回滚到最后成功位置。重复纹理或空白区域不足以推断位移。
5. 首版通过选区排除固定头尾、侧栏、滚动条和动态区域；不自动删除可能属于正文的固定区域。后续再增加可视化忽略区域。
6. 每次成功仅写入底部新增条带。撤销移除最后条带并恢复对应匹配基准；暂停后恢复仍以最后成功帧为基准，不能静默跳过内容。
7. 达到预算时停止追加并提示完成。自动模式向原选定控件发送 WM_MOUSEWHEEL 消息，不移动鼠标，鼠标移出选区不会暂停。目标关闭、最小化、移动或滚动点被其他窗口遮挡时暂停；恢复时仍绑定原控件。已经追加过内容且连续三次滚动无变化时完成并预览；没有进展则提示可能已到底或目标不接受滚动消息，保留手动模式。Esc 取消。手动模式由用户点击完成确认终点。
8. 完成后构建长图并打开宿主预览。预览可裁剪首尾；取消预览释放结果，不自动改写剪贴板。

## 实施顺序

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| P1 | SDK、清单、注册中心、插件管理、托盘入口 | 导入插件后可发现；错误插件不会阻止启动；每个插件一行，启停和版本状态可见 |
| P2 | 选区、实时帧、图像预览和输出服务 | 物理坐标准确，取消闭环，保存/复制/贴图可用 |
| P3 | 拼接算法、分段缓存与官方插件 | 稳定重叠拼接，拒绝歧义，预算与撤销可靠 |
| P4 | 会话 UI、暂停、状态提示和快捷键 | 控制条不遮挡选区，捕获不抢夺目标滚动，退出清理 |
| P5 | 构建发布、开发文档与回归 | 主程序无插件代码依赖；独立插件包可导入；离线加载；验证报告可复现 |

## 验证矩阵

- 算法：已知位移的文字/随机纹理帧、静止、反向、重复内容、无重叠、少量噪声、尺寸变化、撤销、预算、分段拼接像素一致性。
- 插件：独立 SDK 插件加载、私有依赖、SDK 共享、非法清单、重复 ID、初始化异常回滚、执行异常、取消、启停、快捷键冲突和配置保存。
- UI：选区取消、负坐标、150% DPI、控制条避让、暂停/恢复/撤销、预览裁剪与输出、关闭后无残留窗体或文件。
- 回归：构建零错误、语言资源检查、原首选项缩放检查、独立插件包清单与依赖完整、单文件主程序可离线提取并加载官方长截图。

验证通过后在文末记录已完成内容、执行命令和仍需真实软件人工验证的场景。测试产物使用 .local，不纳入发布源文件。

## 后续扩展

随后在当前窗口消息驱动之外增加 UIA 和可选模拟输入驱动，保留手动模式；再增加浏览器专用提供器。未来以新的插件运行器承接 IPC，不将窗体引用或主程序内部类引入稳定契约。现有 SDK 的 UI 相关接口在独立进程模式中需要适配，不能宣称进程内 DLL 无修改即可迁移。

## 实施与验证记录（2026-11-19）

- 主程序、SDK 与独立长截图插件已实现。v0.3.15 在所有发布包中携带官方长截图的 DLL、清单和图标，由宿主在启动时提取并按插件契约加载。详见[接入规范](PLUGIN_DEVELOPMENT.zh-CN.md)。
- “首选项 → 插件”提供导入、HTTPS 包直链下载；每个插件一行，包含名称、版本、状态与启停开关。默认关闭，手动开启立即加载，停用移除贡献并取消活动任务。
- “首选项 → 常规 → 布局”逐个控制内置功能按钮，另列已启用插件的功能按钮。显隐与功能启停独立；不控制整条状态栏，识别状态及快捷键继续可用。
- F1 工具栏按显隐开关紧凑布局，隐藏按钮不留命中区域。插件按钮使用图标与悬浮标题；按钮过多时换行。点击插件按钮复用已框选区域，不需再次框选。
- 长截图人工测试已确认自动滚动生成连续长图，鼠标移出选区不影响捕获，重复捕获与预览正常。789 像素选区的日志显示首步 120 像素校准，后续 360 像素，末步 325 像素。
- 验证程序 1357 项检查通过，覆盖匹配、像素拼接、缓存、预算、两次结果所有权交接、插件依赖隔离、初始化回滚、即时启停、首选项布局、每个按钮显隐、无内置插件依赖、包导入、HTTPS 下载流程（模拟响应）、拒绝越界 ZIP 与取消清理，以及插件 UI 的简体、繁体、英文和深浅主题布局。公共预览另验证了缩放锚点、拖动、边界、裁剪、复制及贴图像素尺寸、键盘和小窗口工具栏布局。八语言各 448 项资源检查通过。
- 原首选项缩放回归更新后 5589 项断言通过（简体中文、英文、德文，17 个子页面、4 种尺寸、150% DPI）。此前独立测试产物分为 `.local/preview-zoom-app/SnipLite.exe` 与 `.local/scroll-alignment-fix-package/sniplite.scroll-capture-0.1.5.snipplugin`；包包含清单、插件 DLL、运行依赖说明与图标 PNG，不带 SDK DLL。
- 0.1.2 的圆角卡片、开关、带图标的操作按钮和独立状态区由插件实现，沿用宿主 StyleWindow 的深浅主题。该界面升级只需替换插件包，不修改宿主或公共 SDK；捕获仍为非模态，结果仍交给宿主公共预览窗口。
- 0.1.3 修复自动滚动的目标判定：显示操作窗前绑定选区中心；在原根窗口内重新识别子控件；比较客户区而非外框；对短暂遮挡提供 2 秒恢复时间。新增回归模拟子控件重建、遮挡恢复、窗口移动／关闭／最小化、访问拒绝，以及消息已执行但超时的场景，确认无覆盖窗口输入、无重复滚动。尚需用户在出现问题的真实应用中复测。
- 0.1.4 针对 338 × 1576 窄长选区的日志新增固定边缘干扰回归，支持左右边缘总计最多六分之一采样列的剔除，仍拒绝重复行、内部大幅变化和无重叠。恢复前先对齐当前帧，避免继续按钮额外滚动导致累计偏离；避免每次采样时按钮和提示反复刷新。
- 打包命令：`./scripts/package-plugin.ps1`。宿主发布与插件包分开发放。当前无在线插件商店；HTTPS 下载需要插件包的直链地址。
- ShareX 本地源码仅用于了解滚动、等待、终点检测的设计思路；滚动驱动、采样匹配、缓存与窗口实现均独立编写。

自动模式依赖目标应用接受标准窗口滚动消息；不响应时可使用手动模式。尚未实现 UIA、浏览器整页和固定区域自动剔除，真实应用兼容性应逐项记录。
