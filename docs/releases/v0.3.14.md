# SnipLite v0.3.14

- **更小的安装包**：移除不再使用的 Windows OCR、Windows SDK/WinRT 投影和 WPF 依赖，保留 .NET 与 WinForms，界面延续现有极简风格。
- **保留本地 OCR**：SimdPaddleOCR + PP-OCRv6 Small、文本方向模型完整保留，离线识别中英文；截图、贴图和翻译使用同一识别入口。识别失败会提示错误，可重新尝试。
- **原生自动框选**：UI Automation 改用 Windows 自带的 COM 服务，保留 Win32/MSAA 辅助检测、遮罩下控件识别、停留重试和单击选择。
- **修复手动复制**：关闭「截图后自动复制」后，点击工具栏复制或按 Ctrl+C 仍会正确写入剪贴板。
- **八语言同步**：更新 OCR 设置说明、首选项预览和第三方许可；保留旧配置的兼容读取。

## 下载

Windows x64 提供三种包含 .NET 运行时的版本，不需要另装 OCR 模型：

- `SnipLite-0.3.14-win-x64-single.exe`：单文件版，下载后直接运行。
- `SnipLite-0.3.14-win-x64-setup.exe`：安装版，提供安装向导、开始菜单快捷方式和卸载入口。
- `SnipLite-0.3.14-win-x64-portable.zip`：解压版，完整解压后运行 `SnipLite.exe`，附带多语言使用说明。

升级前请从托盘退出旧版，再启动或安装新版。可用 `SHA256SUMS.txt` 核验下载文件。已有截图、标注、贴图、扫码、翻译和八语言界面继续保留。

## 验证范围

Release 构建通过，八语言资源和布局检查通过；自包含运行时下完成截图、OCR、扫码、标注、文字编辑、自动框选、翻译、贴图和主题回归。手动复制通过 16 项独立进程读取系统剪贴板的验证。OCR 引擎与模型程序集的哈希和 v0.3.13 一致。

尚未完成干净 Windows 10/11 安装、升级、卸载和所有真实应用的自动框选兼容矩阵；不宣称启动速度、内存或 OCR 准确率因包体优化而提升。详细测量方法和边界见 [包体优化实测记录](https://github.com/GxDongV/SnipLite/blob/v0.3.14/docs/PACKAGE_SIZE_RESULTS.zh-CN.md)。

## English

This release reduces package size by removing the unused Windows OCR path, Windows SDK/WinRT projections and WPF dependencies. The existing WinForms interface, offline SimdPaddleOCR + PP-OCRv6 Small models, text orientation model and eight interface languages are retained. Automatic target detection now uses Windows UI Automation COM alongside Win32/MSAA.

Manual copying from the toolbar or with Ctrl+C now works when automatic capture copying is disabled. All three Windows x64 downloads include the .NET runtime and OCR models. Exit the previous instance before upgrading and verify downloads with `SHA256SUMS.txt`.

Self-contained desktop regression checks passed. Clean Windows installation/upgrade/uninstall and the complete real-application compatibility matrix remain unverified; no startup, memory or OCR accuracy improvement is claimed.
