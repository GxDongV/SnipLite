# SnipLite v0.3.13

- **八语言界面**：新增英语、简体中文、繁體中文、日本語、한국어、Français、Deutsch 和 Español 的完整界面资源，覆盖首选项、托盘菜单、截图标注、OCR、翻译和操作提示。
- **默认跟随系统**：首次启动跟随 Windows 显示语言；可在「首选项 → 常规 → 显示语言」手动切换，即时生效并记住选择。保留已有语言设置，未支持的系统语言回退到英语。
- **切换不中断编辑**：语言切换保留已有截图、标注、识别结果和用户输入。界面语言与 OCR 识别语言、翻译语言独立设置。
- **多语言布局适配**：优化较长标签、提示和下拉选项的显示，保持原有极简风格。
- **八语言使用说明**：README 提供独立语言切换入口，围绕功能、下载和操作说明编写。每种语言均包含截图涂鸦标注和首选项预览，展示矩形、椭圆、箭头、画笔、马克笔、可编辑文字与像素马赛克。

## 下载

Windows x64 提供三个包含 .NET 运行时的版本：

- `SnipLite-0.3.13-win-x64-single.exe`：单文件版，下载后直接运行。
- `SnipLite-0.3.13-win-x64-setup.exe`：安装版，提供安装向导、开始菜单快捷方式和卸载入口。
- `SnipLite-0.3.13-win-x64-portable.zip`：解压版，完整解压后运行 `SnipLite.exe`，附带多语言使用说明。

升级前请从托盘退出旧版，再启动或安装新版。可用 `SHA256SUMS.txt` 核验下载文件。

## English

This release adds eight interface languages: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, French, German and Spanish. New settings follow the Windows display language; manual choices apply immediately and persist. Existing captures, annotations and recognized text are retained when switching languages. Interface, OCR and translation languages remain independent.

The README is now available in all eight languages, with matching annotation examples and Preferences previews. Windows x64 downloads include a single executable, an installer and a portable archive, all with the .NET runtime included. Exit the previous version before upgrading; checksums are provided in `SHA256SUMS.txt`.
