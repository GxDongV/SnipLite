# SnipLite v0.3.15

- **开箱即用的长截图**。三个 Windows x64 下载都自带长截图插件 0.1.6。按 F1 框选滚动区域，再点击长截图图标，也可从托盘菜单启动。插件支持自动滚动、暂停、继续、撤销和手动滚动。
- **长图预览**。在极简窗口中缩放、平移、裁剪、复制、保存或贴图。普通滚轮浏览长图，Ctrl＋滚轮缩放。
- **插件管理**。在「首选项 → 插件」启停插件、导入文件或从 HTTPS 直链下载。「常规 → 布局」可以调整 F1 工具栏按钮。升级会保留已有的长截图停用选择，并优先加载随程序提供的版本。
- **首选项窗口可调整大小**。可拖动窗口边缘或角落。

## 下载

- `SnipLite-0.3.15-win-x64-single.exe` 单文件版，直接运行。
- `SnipLite-0.3.15-win-x64-setup.exe` 安装版，提供安装向导和开始菜单入口。
- `SnipLite-0.3.15-win-x64-portable.zip` 解压版，完整解压后运行 `SnipLite.exe`。

升级前请从托盘退出旧版。三个下载均包含 .NET 运行时，可用 `SHA256SUMS.txt` 核验文件。开发者可参考 [插件接入规范](https://github.com/GxDongV/SnipLite/blob/v0.3.15/docs/PLUGIN_DEVELOPMENT.zh-CN.md)。

## English

All Windows x64 packages include the scrolling screenshot plugin, enabled by default. Press F1, select a scrollable region, and click its toolbar icon, or launch it from the tray menu. The result preview supports zoom, pan, crop, copy, save, and pin. Open Preferences → Plugins to manage plugins, or General → Layout to control capture toolbar visibility. Preferences can be resized by dragging an edge or corner.
