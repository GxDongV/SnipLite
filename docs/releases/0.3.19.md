# SnipLite v0.3.19

所有 Windows x64 安装包均内置长截图 0.1.15。长截图完成后直接打开主程序的「图像预览」。水印等图片处理插件也使用同一个窗口。

- 窗口打开时显示在前方，沿用长截图预览的尺寸和工具栏，提供复制、保存、适应宽度、适应窗口、原尺寸和缩放图标。
- 在预览图片上右键，可使用贴图、裁剪和已启用的插件操作。
- 长截图的独立预览窗口和二次打开预览的按钮已移除。复制和保存使用主程序的输出设置。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.19-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.19-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.19-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。 [长截图 0.1.15 发布说明](https://github.com/GxDongV/SnipLite-Plugin-Catalog/releases/tag/scroll-capture-v0.1.15)

## English

SnipLite v0.3.19 bundles Scroll Capture 0.1.15. Scrolling screenshots and image-processing results open in the same foreground preview. It uses the scrolling screenshot toolbar for copying, saving, fitting, and zooming. Right-click the image to pin, crop, or use an enabled plugin action.
