# SnipLite v0.3.10

- **界面与主题**。首选项采用侧边导航、圆角设置卡片和线条图标。首选项、截图工具栏、翻译栏与菜单跟随 Windows 浅色／深色模式，运行中切换即时生效，并支持系统高对比度。
- **字体直接选择**。点击文字工具的字体按钮直接展开列表，支持鼠标滚轮、拖动滚动条和键盘选择。列表显示当前字体，增加边框并限制高度，靠近屏幕底部时向上展开。修复字体较多时打开列表长时间卡顿的问题，移除额外的“字体与字号…”入口。
- **选区调整更清楚**。增强选区边角控制点的可见性，尺寸提示自动避开工具栏。拖动边角调整选区时显示像素放大镜，改善放大镜跟随和重绘，松开鼠标后结束调整。
- **应用图标**。程序文件、窗口、安装程序和托盘使用新的 SnipLite 图标。默认托盘图标跟随 Windows 任务栏明暗设置，支持彩色与自定义图标。

## 下载与升级

| 文件 | 使用方式 |
| --- | --- |
| `SnipLite-0.3.10-win-x64-single.exe` | 单文件版，下载后直接运行 |
| `SnipLite-0.3.10-win-x64-setup.exe` | 安装版，提供开始菜单和卸载入口 |
| `SnipLite-0.3.10-win-x64-portable.zip` | 解压版，完整解压后运行 `SnipLite.exe` |

三个版本均适用于 Windows x64，包含 .NET 运行时与本地 OCR 模型。目标系统最低为 Windows 10 2004（Build 19041），实际可用性取决于运行时与系统组件。

升级前请从托盘退出正在运行的 SnipLite。若开机启动指向旧程序路径，可在新版首选项中关闭再开启开机启动，更新启动路径。可用附带的 `SHA256SUMS.txt` 核验下载文件。
