## SnipLite v0.3.8 · 首次公开发布

Windows 截图、标注、置顶贴图、本地 OCR 与二维码识别工具，采用 MIT 许可证。

### 下载哪个版本？

| 文件 | 适用方式 |
| --- | --- |
| **SnipLite-0.3.8-win-x64-single.exe** | 单文件版：下载后直接运行，无需解压或安装 |
| **SnipLite-0.3.8-win-x64-setup.exe** | 安装版：通过向导安装，提供开始菜单快捷方式及卸载入口 |
| **SnipLite-0.3.8-win-x64-portable.zip** | 解压版：完整解压后运行 SnipLite.exe |

三个版本均为 **Windows x64**，包含 .NET 运行时，无需额外安装 .NET。系统最低要求为 Windows 10 2004（Build 19041）；OCR 需要系统安装对应的识别语言包。单文件版首次启动会释放原生依赖，因此可能稍慢。

### 功能亮点

- F1 截图，支持窗口与可访问控件自动框选、停留重试、像素放大镜及 RGB / HEX 取色。
- 矩形、椭圆、多种箭头、画笔、半透明马克笔、像素马赛克与橡皮擦。
- 文字可再次编辑、插入、选中替换、调整字体字号、拖动与缩放，并支持撤销、重做。
- 截图工具栏内置 OCR 原图选字；二维码 / 条码结果在工具栏下方直接显示并复制。
- F3 置顶贴图，支持缩放、透明度、隐藏恢复、分组和文字转图片。
- 帮助页提供可点击的 GitHub、问题反馈链接，以及离线许可证查看。

### 使用提示

启动后常驻系统托盘，没有主窗口。F1 开始截图，F3 贴图；右键托盘图标打开首选项或退出。截图过程中，鼠标右键可取消。切换三个版本前，请先从托盘退出正在运行的实例。

本次为早期版本：自动框选依赖目标应用的可访问性信息；历史仅在当前运行会话内保留，暂不支持滚动长截图或贴图内继续标注。反馈问题请附版本、Windows 版本、屏幕缩放比例及复现步骤。
