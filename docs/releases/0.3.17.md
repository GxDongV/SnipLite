# SnipLite v0.3.17

- **确认后卸载插件**。在「首选项 → 插件 → 已安装插件」中，每个可卸载插件的最右侧都有「卸载插件」按钮。对话框显示插件名称并默认选中「取消」。确认后在下次重启时生效，保留插件设置、数据和快捷键。
- **长截图可卸载或恢复内置版本**。内置长截图也支持卸载。安装过独立更新包时，可选择「恢复内置版本」切回随程序提供的 0.1.6。
- **发现插件**。在「首选项 → 插件 → 发现插件」浏览官方目录，并下载安装或更新。SnipLite 检查兼容性、安装包 SHA-256 和包内清单。长截图 0.1.7 已可从目录更新。
- **插件兼容性**。继续使用 API v1，支持命令、截图、图像处理和导出扩展。插件开发可参考[接入规范](https://github.com/GxDongV/SnipLite/blob/v0.3.17/docs/PLUGIN_DEVELOPMENT.zh-CN.md)。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.17-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.17-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.17-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。

## English

- Uninstall plugins from the right edge of their row under **Preferences → Plugins → Installed plugins**. Confirm the action to apply it on restart. Plugin settings, data and hotkeys are kept.
- Uninstall Scroll Capture or restore the bundled version after installing a standalone update.
- Browse and install compatible packages from the official catalog under **Discover plugins**. SnipLite verifies the package checksum and manifest before installation.
- The public plugin SDK remains on API v1.
