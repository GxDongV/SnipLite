# SnipLite v0.3.20

在「首选项 → 常规」开启「以管理员身份开机启动」后，确认一次 Windows 授权即可立即以管理员权限重启 SnipLite，并在以后登录 Windows 时自动以管理员权限启动。这个选项适用于需要在任务管理器等管理员窗口处于前台时使用单键 `F1` 截图的场景。

- 如果升级前已经开启此选项，可以关闭后重新开启，立即触发管理员重启。
- 取消授权时，当前实例继续运行，原来的启动设置保持有效。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.20-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.20-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.20-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。

## English

Turning on **Launch as administrator at sign-in** now restarts SnipLite with administrator rights after you approve the Windows prompt. The same option schedules an elevated launch at future Windows sign-ins. This helps when you use the single-key `F1` shortcut while an elevated window such as Task Manager is in focus. If the option was already enabled before upgrading, toggle it off and back on to restart immediately.
