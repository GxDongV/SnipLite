# SnipLite v0.3.12

- **贴图历史统一**。截图、剪贴板图片和剪贴板文字生成的贴图都进入同一份历史。关闭贴图后可连续按 F3，从新到旧逐张恢复。取消 Tab 切换历史选区。
- **贴图缩放**。滚轮缩放时左上角短暂显示原图比例。普通缩放范围为 10%–500%，并受最大窗口尺寸限制。
- **截图输出**。启用自动复制时，普通截图选区确定或调整后会自动复制图像。保存音效覆盖手动另存、快速保存和自动保存。
- **截图音效**。新增 0.3 秒内置提示音。支持试听、更换 WAV 和恢复默认。复制和保存音效默认关闭，已有设置继续保留。
- **快捷键编辑**。点击「更改」后录入，再确认保存。重复或被占用的组合键会提示原因并保留原绑定。
- **文字贴图**。修复页边距较大时图片超出最大宽度的问题。

Windows x64 提供单文件版、安装版和解压版。升级前请退出当前 SnipLite。可用 SHA256SUMS.txt 核验下载文件。
