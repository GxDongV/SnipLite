# SnipLite v0.3.21

## 截图与标注

- 确认选区前，鼠标指向图标或控件，直接上滚选择父元素、下滚选择子元素。启用自动放大镜时，拖动框选仍可查看局部像素和选区边缘。
- 单击截图界面上的「宽 × 高」标签，可在框选前后输入精确的像素尺寸。打开尺寸弹窗时会保留截图界面。
- 选中对应工具后，可重新选择已有标注并移动、缩放或修改样式。使用 `Del` 删除、`Ctrl+Shift+C` 复制、`Ctrl+Shift+V` 粘贴，或按住 `Ctrl` 拖动克隆。
- 绘制矩形、椭圆或拖动已有图形的缩放手柄时，按住 `Shift` 可得到正方形或正圆。
- 拖动粗细滑块时，截图选区中心显示实际笔触大小和当前值、最大值。松手后收起预览。

## 贴图与 OCR

- 贴图显示后会在本机用原图识别文字。直接从文字处拖动选字，按 `Ctrl+C` 复制。拖动空白处可移动贴图。未选中文字时，`Ctrl+C` 复制图片。
- 校正截图和贴图 OCR 的行首、行尾字符边界，改善首尾字的高亮覆盖和鼠标命中。
- 对连续排列的位图像素直接读取缓冲区，减少 OCR 的临时分配和像素拷贝。

## 输出与首选项

- 在「输出 → 剪贴板」开启「复制图片时同时复制 PNG 文件」，复制截图或贴图后即可在资源管理器中按 `Ctrl+V` 粘贴为 PNG。文件名沿用输出设置。
- 在「输出 → 文件」可设置自动保存保留规则。默认全部保留，也可保留最新 N 张或清理超过 N 天的截图。启用对应规则后，每次启动约两分钟后清理一次，仅处理新版登记的自动保存截图。
- 在「常规 → 布局」拖动工具栏预览里的按钮即可调整顺序，松手后自动保存。内置按钮和已启用的插件按钮都支持排序。
- 首选项下拉菜单的高亮与点击区域覆盖整行，弹出框四角统一使用圆角。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.21-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.21-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.21-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。

## English

- Scroll over a control to select its parent or child before capturing. The automatic magnifier stays visible while dragging, and the size label opens an editor for exact pixel dimensions.
- Re-select annotations to move, resize, restyle, delete, copy, paste, or duplicate them. Hold Shift while drawing or resizing a rectangle or ellipse to make a square or circle. The stroke-width slider shows a live size preview.
- Select and copy text directly on pinned images after local OCR. Capture and pin OCR both improve first- and last-character selection.
- Copy captures and pins as PNG files for pasting into File Explorer. Configure automatic-save retention by count or age, with one cleanup about two minutes after launch.
- Drag built-in and plugin buttons in the toolbar preview to reorder them. Preferences dropdowns use full-row highlights and rounded corners.
