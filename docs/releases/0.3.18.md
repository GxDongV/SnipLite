# SnipLite v0.3.18

所有 Windows x64 安装包均内置长截图 0.1.13。

- **固定区域各保留一次。** 顶栏放在长图开头，左右固定侧栏保留在首屏两侧，底栏取最后一帧并放在长图末尾。
- **长图预览自动弹到前台。** 插件自带预览窗口，使用图标按钮复制、保存、缩放和适应窗口。贴图、裁剪和扩展可从工具栏打开。
- **简化长截图面板。** 暂停时显示操作提示。匹配数据仍可在日志中查看。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.18-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.18-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.18-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。也可为现有 SnipLite 单独安装新版插件。 [长截图 0.1.13 发布说明](https://github.com/GxDongV/SnipLite-ScrollCapture/releases/tag/v0.1.13)

## English

SnipLite v0.3.18 bundles Scroll Capture 0.1.13. Long screenshots place fixed headers at the top, fixed sidebars beside the first viewport, and fixed footers at the end. The plugin opens its own preview in front with icon buttons for copying, saving, and zooming. The capture panel displays a short message when it pauses and records matching details in the log.
