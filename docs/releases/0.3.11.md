# SnipLite v0.3.11

- 快捷键支持 Win 组合键，包括 Win+F1（组合键可用时）。
- 放大镜显示屏幕坐标和选区相对坐标。默认 Ctrl+Shift+C 复制坐标，可在首选项修改。
- 扩大 OCR 划词的边缘命中范围和首尾字高亮。Ctrl+Alt+O 选区后进入划词模式。
- 管理员开机启动配置移到后台运行，避免等待 UAC 或任务计划程序时阻塞设置窗口。
- 默认 Ctrl+Alt+T 截图翻译，选区后自动翻译，快捷键可修改。
- 首选项明确标注「隐藏 HEX 颜色值开头的 #」。
- 「首选项 → 更新」支持检查 GitHub 最新正式发布、下载安装包和 SHA-256 校验。下载后可手动安装。

Windows x64 提供单文件版、安装版和解压版。升级前请从托盘退出 SnipLite，可用 SHA256SUMS.txt 校验下载。
