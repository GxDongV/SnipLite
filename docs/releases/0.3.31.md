# SnipLite v0.3.31

## 屏幕录制

- 在「首选项 → 插件 → 发现插件」安装并启用「屏幕录制」，然后按 F1 框选，在截图工具栏的插件组点击「录制」。[插件源码与使用说明](https://github.com/GxDongV/SnipLite-ScreenRecorder)
- 录制支持开始、暂停、继续、结束和复制当前帧。可选择 MP4、GIF、APNG 或动态 WebP。MP4 支持麦克风、系统声音和独立 WAV 音轨。
- 录制中可以再次按 F1 截图和标注。移动截图十字准线时，录屏选区、工具栏、状态栏和键鼠特效仍可见。
- 录屏设置可从主程序首选项或录制工具栏打开。设置项包括保存目录、清晰度、帧率、编码器、采集接口和工具栏位置。录制中可只读查看设置。

## Windows x64 下载

- `SnipLite-0.3.31-win-x64-single.exe` 可直接运行。
- `SnipLite-0.3.31-win-x64-setup.exe` 提供安装向导。
- `SnipLite-0.3.31-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本都包含 .NET 运行时。可用 `SHA256SUMS.txt` 校验下载。

## English

Install Screen Recorder in **Preferences → Plugins → Discover plugins**. Select a region with F1 and choose Record in the screenshot toolbar. The recorder exports MP4, GIF, APNG, and animated WebP. You can take and annotate screenshots during recording while the recording controls and input effects stay visible.
