# SnipLite v0.3.16

- **插件管理**。可直接导入同一插件的较新版本，也可卸载第三方插件或恢复内置长截图版本。更新和卸载在重启后生效，并保留插件设置与快捷键。内置长截图插件为 0.1.6。
- **统一设置快捷键**。已启用插件的命令显示在「首选项 → 控制 → 全局快捷键」末尾，与内置命令共用冲突检查。诊断日志记录热键注册结果和 Windows 错误码。
- **截图与文字标注**。「首选项 → 截屏 → 行为」新增松开鼠标后自动复制并退出截图的开关。文字编辑光标改为较粗的闪烁竖线，并随屏幕缩放调整。
- **实时布局预览**。「首选项 → 常规 → 布局」实时展示工具栏，窄窗口下保持单排。统一选中子标签的描边，并为首选项、托盘和贴图菜单补齐功能图标。
- **通知与音效**。右下角通知采用跟随系统主题的卡片样式，可在「首选项 → 输出 → 文件」关闭。复制截图附带的自动保存静音，复制音效由复制开关控制。
- **稳定性**。改进 OCR 排队取消，以及截图翻译、贴图和首选项关闭时的资源释放。

## Windows x64 下载

- 单文件版 `SnipLite-0.3.16-win-x64-single.exe` 可直接运行。
- 安装版 `SnipLite-0.3.16-win-x64-setup.exe` 提供安装向导。
- 解压版 `SnipLite-0.3.16-win-x64-portable.zip` 完整解压后运行 `SnipLite.exe`。

三个版本均包含 .NET 运行时和长截图插件。可用 `SHA256SUMS.txt` 校验文件。

## English

- Update plugins in place, uninstall third-party plugins, or restore the bundled scrolling screenshot plugin. Manage plugin hotkeys alongside built-in shortcuts in Preferences.
- Add an option to copy a screenshot and close the capture overlay as soon as the selection is made. The text insertion caret is now a thicker vertical line.
- Preview the capture toolbar live in Preferences. The preview stays on a single row at narrow widths. Subtab borders and menu icons have also been updated.
- Operation notifications use themed cards and have a visibility switch. Automatic saves that accompany screenshot copying are silent.
- Improve queued OCR cancellation and resource cleanup.
