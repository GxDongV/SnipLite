# SnipLite v0.3.9

- **截图翻译**。选区后点击「译」，译文会覆盖到原文位置。可切换原文和译文、复制文字，或保存和贴出当前画面。首选项可设置默认服务，截图翻译栏也可切换本次使用的服务。
- **翻译服务**。默认使用必应网页翻译，也可选 Google、MyMemory 或 Microsoft Azure。必应、Google 和 MyMemory 无需配置密钥。MyMemory 需要手动选择源语言，Microsoft Azure 需要用户配置自己的 API Key。网页接口遇到限流时可切换服务。在线翻译发送识别出的文字，截图 OCR 在本机完成。
- **OCR 识别**。内置 PP-OCRv6 Small 模型，支持离线识别中英文。划词时可以从字符边缘开始拖选。OCR 保留完整工具栏，下方显示识别状态和复制按钮。可在首选项切换至 Windows OCR。
- **F3 贴出当前截图**。选区确定后按 F3，直接贴出当前画面及标注。未打开截图时，F3 可贴出剪贴板内容或恢复贴图。

## 下载与升级

| 文件 | 使用方式 |
| --- | --- |
| `SnipLite-0.3.9-win-x64-single.exe` | 单文件版，下载后直接运行 |
| `SnipLite-0.3.9-win-x64-setup.exe` | 安装版，提供开始菜单和卸载入口 |
| `SnipLite-0.3.9-win-x64-portable.zip` | 解压版，完整解压后运行 `SnipLite.exe` |

三个版本均适用于 Windows x64，最低要求 Windows 10 2004（Build 19041），包含 .NET 运行时与本地 OCR 模型。升级前请从托盘退出正在运行的 SnipLite。若开机启动指向旧的预览文件，可在新版首选项中重新关闭、开启开机启动以更新路径。

可用附带的 `SHA256SUMS.txt` 核验下载文件。
